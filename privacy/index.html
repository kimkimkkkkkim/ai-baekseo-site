3. 플러그인 사용 정보

AI 백서는 독립 서버나 별도 분석 시스템을 운영하지 않습니다. 따라서 운영자는 플러그인 사용 과정에서 다음 정보를 자동으로 수집·저장·집계하지 않습니다.

  • 사용자가 입력한 질문, 첨부 자료 및 AI가 생성한 답변
  • 사용자 이름, 계정 식별자, IP 주소 또는 기기 식별자
  • 질문 빈도, 질문 범주, 기능 사용 기록 및 행동 분석 정보
  • 비밀번호, 인증 토큰 또는 연결 서비스의 인증정보

플러그인은 사용자가 이용하는 ChatGPT 또는 Codex 환경 안에서 실행됩니다. 해당 플랫폼에서의 데이터 처리는 플랫폼 운영자의 정책과 사용자가 선택한 계정·워크스페이스 설정에 따릅니다.

플랫폼 대화 산출물

0.2.0은 사용자의 답이나 자료로 판단·행동이 크게 달라진 경우, 플랫폼이 명시적으로 지원하면 처음 요청 기준 답변을 Markdown 대화 산출물로 제공하도록 설계되었습니다. 생성 전 민감정보를 다시 검사해 비밀번호·인증정보는 생략하고 개인 식별정보·개별 고객 또는 직원 정보·핵심 회사 기밀은 비식별화·일반화합니다. 안전한 비교가 불가능하면 산출물과 링크를 만들지 않습니다. 이 산출물은 현재 대화의 결과이며 운영자가 운영하는 별도 파일 서버나 데이터베이스에 저장되지 않습니다.

  • 운영자는 대화 산출물을 로컬 도메인 문서, 플러그인 패키지, 별도 색인 또는 이후 요청의 자동 검색 대상으로 편입하지 않습니다.
  • 일반적인 작업공간 파일 쓰기 기능을 대화 산출물 지원으로 간주하지 않으며, 이용자의 명시적 저장 요청 없이 작업공간 파일로 쓰지 않습니다.
  • 산출물의 표시·보존·삭제 기준은 이용 중인 플랫폼의 기능과 계정 설정을 따릅니다.

4. 선택적 로컬 도메인 문맥

AI 백서는 사용자가 반복해서 사용하는 용어와 업무 규칙을 사용자의 작업공간에 있는 .ai-vexer/domain-context.md 파일에서 선택적으로 읽을 수 있습니다.

  • 현재 요청과 관련된 경우에만 정해진 경로의 파일을 읽습니다.
  • 파일이 없으면 생성을 강요하지 않고 그대로 업무를 진행합니다.
  • 파일을 만들거나 수정하기 전 저장할 요약을 보여주고 명시적 동의를 받습니다.
  • 대화 원문이 아니라 사용자가 확인한 최소한의 요약만 기록합니다.
  • 비밀번호, 인증정보, 개인 식별정보, 개별 고객·직원 정보 및 핵심 회사 기밀은 저장하지 않습니다.

이 파일은 사용자 소유의 로컬 문서이며 플러그인 패키지에 포함되거나 운영자에게 자동 전송되지 않습니다. 이용자는 언제든 파일을 확인·수정·삭제할 수 있습니다.
